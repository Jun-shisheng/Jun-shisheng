## 🚧 What I'm building

| Project | What it does |
| :-- | :-- |
| **[AI_Music](https://github.com/Jun-shisheng/AI_Music)** | Local-first AI music studio. An LLM writes the lyrics, your own GPU renders the audio, and every take gets measured before it ships. |
| **[Novel_AI](https://github.com/Jun-shisheng/Novel_AI)** | A Word add-in for AI-assisted fiction: hotkey-driven character polish, paragraph continuation and whole-text summaries on top of the DeepSeek API. |
| **[Timbre_distillation](https://github.com/Jun-shisheng/Timbre_distillation)** | End-to-end voice cloning: multi-source capture → UVR5 stem separation → Audition cleanup → RVC v2 model. |
